# 🍴 Grounded Restaurant Researcher v2026

An AI-powered agentic workflow that finds local restaurants using live web grounding.

### 🚀 Key Features
- **Live Grounding:** Uses Gemini 2.0 Google Search tool to prevent hallucinations.
- **Sentiment Analysis:** Scrapes Reddit and Google reviews to calculate a "Value Score."
- **Automated Delivery:** Formats results in an HTML table and sends via SMTP (Gmail).
- **Cost Observability:** Real-time token and API cost tracking in the UI.

### 🛠️ Tech Stack
- **Language:** Python
- **AI Model:** Google Gemini 2.5 Flash Lite
- **Interface:** Streamlit (Cloud Deployed)
- **Deployment:** GitHub CI/CD to Streamlit Community Cloud
